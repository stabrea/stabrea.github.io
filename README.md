# stabrea.github.io

Personal portfolio website for Taofik Bishi — Finance & Cybersecurity Professional.

## Stack

- HTML5
- CSS3 (no preprocessor)
- Vanilla JavaScript (no frameworks)

## Deployment

Hosted on GitHub Pages. Push to `main` and the site deploys automatically.

## Local Preview

Open `index.html` in a browser, or use any static file server:

```bash
npx serve .
```
